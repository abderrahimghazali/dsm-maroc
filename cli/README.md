# dsm-maroc

CLI for **DSM — Système de Design du Maroc**: a trilingual (العربية · ⵜⴰⵎⴰⵣⵉⵖⵜ · Français), RTL-first design system for Moroccan public digital services, built on Next.js 16, Tailwind CSS v4 and Base UI.

```bash
npx dsm-maroc@latest init          # foundations (tokens, utilities), all components, fonts, patterns
npx dsm-maroc@latest add button    # or add a single component and what it imports
npx dsm-maroc@latest list
```

The sources are copied into your project under `src/dsm/` (or `dsm/`), so you own the code.
Documentation: https://dsm-maroc.vercel.app
